* Plan — Build Steps

This document describes the step-by-step process of building this app from
scratch, in the order a developer would tackle them.

** Phase 0 — Scaffold

- [X] Create solution: =dotnet new sln -n lvl2-task-1=
- [X] Create three projects:
  - =dotnet new classlib -n FileOrganizer.Core=
  - =dotnet new console -n FileOrganizer.Cli=
  - =dotnet new avalonia.mvvm -n FileOrganizer.Gui=
- [X] Add project references:
  - Cli → Core, Gui → Core
- [X] Add solution references: =dotnet sln add ...=

** Phase 1 — Core Library (=FileOrganizer.Core=)

*** 1.1 Models

- [X] Create =Models/FileEntry.cs=
  - Properties: SourcePath, FileName, Extension, Category, TargetFolder, SizeBytes, IsMatchedByPattern
  - Override =Equals()=/=GetHashCode()= on SourcePath (Bug 4 fix)
- [X] Create =Models/OrganizerConfig.cs=
  - Properties: SourceDirectory, NamedPatterns, DryRun, CaseSensitive, Reverse, Interactive, UseRegex

*** 1.2 Services

- [X] Create =Services/FileScanner.cs=
  - Enumerate files in directory
  - Wrap per-file =FileInfo= construction in try/catch (=UnauthorizedAccessException=, =PathTooLongException=) — Bug 2 fix
  - Return =List<FileEntry>=
- [X] Create =Services/CategoryResolver.cs=
  - Dictionary mapping extensions to category names (=imgs=, =docs=, =aud=, =vid=, =archives=, =installers=)
  - =Resolve()= returns matching category or ="others"=
- [X] Create =Services/NamedPatternResolver.cs=
  - =Match()= iterates files × patterns
  - Regex branch wraps =Regex.IsMatch()= in try/catch — Bug 3 fix
  - Keyword branch uses =.Contains()=
  - Folders are sanitised via =SanitizeFolderName()=
- [X] Create =Services/FileMover.cs=
  - =Move()=: group entries by =TargetFolder=, =Directory.CreateDirectory()=, =File.Move()=, handle name collisions
  - =Unorganize()=: scan subdirs, move files up, handle collisions
  - Size captured before move — Bug 1 fix
  - Dry-run support (log only, no filesystem changes)
  - Progress reporting via =IProgress<double>=

*** 1.3 Orchestrator

- [X] Create =FileOrganizer.cs=
  - =Run(OrganizerConfig)=: dispatch to interactive or one-shot or reverse
  - =RunInteractive()=: dashboard loop with Container/Patterns/General/Reverse phases
  - =RunReverse()=: calls =_mover.Unorganize()=
  - =ContainerPhase()=: user selects files by index → moves to named folder
  - =PatternsPhase()=: user enters patterns → resolve and move
  - =GeneralPhase()=: categorise all remaining files by extension
  - =ReversePhase()=: undo organisation
