* FaceRank — Development Plan

** Goal
Build a cloud-integrated Elo-based "Hot or Not" voting web app (inspired
by FaceMash from The Social Network), covering all 4 Azure objectives:
App Services, Blob Storage, Functions, CI/CD.

** Constraints
- .NET 10.0, Razor Pages, SQLite (local), Azure Blob (prod)
- Gender-separated vote pages and leaderboards
- Seed data of 20 celebrities for demo

** Phase 1 — Scaffold & Domain Model

*** 1.1 Create solution
- [x] ~dotnet new slnx~ → ~FaceRank.slnx~
- [x] Create 3 projects:
  - ~src/FaceRank.Core~ (classlib, shared domain)
  - ~src/FaceRank.Web~ (razorpages, web frontend)
  - ~src/FaceRank.Functions~ (azure functions)

*** 1.2 Core models
- [x] ~Models/Person.cs~: Id, Name, Gender, ContactInfo, AvatarUrl,
  EloRating (default 1400), VotesCount, CreatedAt
- [x] ~Models/Vote.cs~: Id, WinnerId, LoserId, VoterIp, CreatedAt,
  Winner + Loser nav props

*** 1.3 Elo rating service
- [x] ~Services/EloService.cs~: static Calculate() with K=32,
  400-point divisor
  - #baka: expected = 1 / (1 + 10^((opponent - player) / 400))
    standard Elo formula; 400 scales chess ratings

*** 1.4 EF Core DbContext
- [x] ~Data/FaceRankDbContext.cs~: DbSet<Person>, DbSet<Vote>,
  indexes on Gender + EloRating, Vote FK config with NoAction delete
