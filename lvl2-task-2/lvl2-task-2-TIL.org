*  MVC Architecture

| Part       | Responsibility        |
|------------+-----------------------|
| Model      | Data + business logic |
| View       | UI / HTML             |
| Controller | Handles requests      |



- Folder Structure:Typical ASP.NET Core MVC project:

#+begin_src text
MyApp/
│
├── Controllers/
├── Models/
├── Views/
├── wwwroot/
├── Program.cs
└── appsettings.json
#+end_src



- `Views/` Contains Razor pages (=.cshtml=).

- wwwroot/ for Static files: - CSS - JS - images
    Equivalent to =public/= in other frameworks.




*  Controllers  #baka
Controllers handle incoming HTTP requests.

#+begin_src csharp
using Microsoft.AspNetCore.Mvc;

public class HomeController : Controller
{
    public IActionResult Index()
    {
        return Content("Hello from controller");
    }
}
#+end_src


** Common Return Types in Controllers
| Method       | Purpose          |
|--------------+------------------|
| =View()=     | Render HTML page |
| =Content()=  | Plain text       |
| =Json()=     | JSON response    |
| =Redirect()= | Redirect user    |

*  Razor Pages vs MVC

ASP.NET Core has two main styles: MVC, Razor pages

| MVC                   | Razor Pages            |
|-----------------------+------------------------|
| Controller-centered   | Page-centered          |
| Better for large apps | Simpler for small apps |
| More structured       | Faster to build        |


** Razor Pages Example
#+begin_src text
Pages/
 └── Index.cshtml
 └── Index.cshtml.cs
#+end_src

Instead of separate controller.


*  Middleware: the code that runs while processing the request

** Example Middleware 
Inside =Program.cs=:

#+begin_src csharp
  app.UseRouting();
  app.UseAuthentication();
  app.UseAuthorization();
#+end_src

Each middleware does something.


** Common Middleware

| Middleware              | Purpose          |
|-------------------------+------------------|
| =UseRouting()=          | URL routing      |
| =UseStaticFiles()=      | Serve CSS/images |
| =UseAuthentication()=   | Login system     |
| =UseAuthorization()=    | Permissions      |
| =UseExceptionHandler()= | Error handling   |
